# Web Development Journey

This repository tracks my day-by-day progress as I learn web development. I upload daily lecture topics, practice codes, and hands-on tasks here.

---

## 📅 Day-by-Day Learning Log

### 🔹 Day 1: HTML Basics & Core Structure
*   **HTML Architecture:** Explored the basic layout and essential structure of an HTML document.
*   **Tags & Meta Data:** Learned the purpose of standard HTML tags and how `<meta>` tags work behind the scenes.
*   **Images (`<img>`):** Mastered adding images using both internal (local files) and external (web URLs) source paths.

### 🔹 Day 2: Hyperlinks
*   **Navigation (`<a>`):** Learned how to use the Anchor tag to link pages together and connect external websites.

### 🔹 Day 3: Multimedia & Structural Tables
*   **Audio Embedding (`<audio>`):** 
    *   Learned how to add MP3 files to a webpage.
    *   Utilized key attributes: `controls`, `autoplay`, `muted`, and `loop`.
*   **Video Embedding (`<video>`):** 
    *   Configured multimedia streaming with local or external video elements.
    *   Applied identical behavioral attributes (`controls`, `autoplay`, `muted`, `loop`).
*   **Data Layouts (`<table>`):** 
    *   Structured complex data arrays using `<tr>` (Rows), `<th>` (Headers), and `<td>` (Data cells).
    *   Manipulated cell structures using `rowspan` and `colspan` formatting attributes.
    *   **Completed Tasks:** Constructed dynamic data tables and built a custom chessboard interface.
